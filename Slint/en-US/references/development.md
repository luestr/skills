# Application development topics

The official Guide also includes these application-development topics, which should not be omitted:

- **Debugging Techniques**: debugging Slint UI, bindings, and host-language integrations.
- **Focus Handling**: keyboard focus, focus chains, and interactive controls.
- **Translations**: application localization and translation workflows.
- **Font Handling**: font loading, font assets, and cross-platform font configuration.
- **Custom Controls**: composing or extending reusable controls.
- **Drag and Drop**: implementing drag-and-drop interactions.
- **Best Practices**: organizing `.slint` files, components, state, and host logic.
- **Third Party Libraries**: integrating third-party libraries with Slint applications.

Source: [App Development](https://docs.slint.dev/latest/docs/slint/guide/development/).
