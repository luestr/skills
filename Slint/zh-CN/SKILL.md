# Slint v1.17.1 技能

## 使用方式

1. 先阅读 [`references/overview.md`](references/overview.md) 选择主题。
2. 需要应用开发实践时阅读 [`references/development.md`](references/development.md)。
3. 编写 UI 前阅读 [`references/language.md`](references/language.md)。
4. 需要运行项目时阅读 [`references/integrations.md`](references/integrations.md)。
5. 涉及发布平台、渲染后端或工具链时阅读 [`references/platforms-and-tools.md`](references/platforms-and-tools.md)。
6. 需要完整示例时阅读 [`references/tutorial.md`](references/tutorial.md)。

## 版本与来源

本技能按 Slint `v1.17.1` 整理。官方页面的 `/latest/` 可能指向未发布版本；实现细节应以对应版本的官方文档和 API 为准。
