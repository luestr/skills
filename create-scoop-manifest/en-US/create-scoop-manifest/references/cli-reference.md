## Command overview

The output of `scoop help` (28 commands):

```text
alias        Manage scoop aliases
bucket       Manage Scoop buckets
cache        Show or clear the download cache
cat          Show content of specified manifest
checkup      Check for potential problems
cleanup      Cleanup apps by removing old versions
config       Get or set configuration values
create       Create a custom app manifest
depends      List dependencies for an app, in the order they'll be installed
download     Download apps in the cache folder and verify hashes
export       Exports installed apps, buckets (and optionally configs) in JSON format
help         Show help for a command
hold         Hold an app to disable updates
home         Opens the app homepage
import       Imports apps, buckets and configs from a Scoopfile in JSON format
info         Display information about an app
install      Install apps
list         List installed apps
prefix       Returns the path to the specified app
reset        Reset an app to resolve conflicts
search       Search available apps
shim         Manipulate Scoop shims
status       Show status and check for new app versions
unhold       Unhold an app to enable updates
uninstall    Uninstall an app
update       Update apps, or Scoop itself
virustotal   Look for app's hash or url on virustotal.com
which        Locate a shim/executable (similar to 'which' on Linux)
```

## Per-command options

### `scoop install <app> [options]`

```text
scoop install git                                        # from local buckets
scoop install gh@2.7.0                                   # specific version (looks up sqlite cache → git history → generated by autoupdate)
scoop install https://.../runat.json                      # manifest from a URL
scoop install https://.../neovim.json@0.9.0               # URL + version
scoop install .\path\to\app.json                          # local manifest
scoop install .\path\to\app.json@version                  # local manifest + version
```

| Option | Meaning |
|---|---|
| `-g, --global` | Global install (requires administrator) |
| `-i, --independent` | Do not install dependencies automatically |
| `-k, --no-cache` | Do not use the download cache |
| `-s, --skip-hash-check` | Skip hash verification (use with caution) |
| `-u, --no-update-scoop` | Do not self-update Scoop first when it is out of date |
| `-a, --arch <32bit\|64bit\|arm64>` | Specify the architecture (when the manifest supports it) |

Version resolution order: exact sqlite match → the bucket's git history (`use_git_history` defaults to `$true`) → generate on the fly from `autoupdate` → abort if all of them fail.

### `scoop update [<app>] [options]`

```text
scoop update              # update Scoop itself + the manifests of all buckets
scoop update curl         # update a single app
scoop update *            # update every installed app
```

| Option | Meaning |
|---|---|
| `-f, --force` | Force an update even when there is no new version |
| `-g, --global` | Update globally installed apps |
| `-i, --independent` | Do not install dependencies automatically |
| `-k, --no-cache` | Do not use the cache |
| `-s, --skip-hash-check` | Skip hash verification |
| `-q, --quiet` | Less output |
| `-a, --all` | Equivalent to `*` |

Side effect: `scoop update` is triggered automatically once every 3 hours (during install/update/download/virustotal). Old versions are not deleted — they are kept for `reset` until `scoop cleanup`.

### `scoop uninstall <app> [options]`

| Option | Meaning |
|---|---|
| `-g, --global` | Uninstall a global app |
| `-p, --purge` | Also delete persist data |

### `scoop cleanup <app> [options]`

| Option | Meaning |
|---|---|
| `-a, --all` | Clean everything (equivalent to `*`) |
| `-g, --global` | Clean old versions of global apps |
| `-k, --cache` | Also delete expired download cache |

### `scoop search <query>`

- No query: list all available apps.
- `use_sqlite_cache` enabled: the query does **partial matching** against app names, binary names, and shortcuts.
- Not enabled: the query is treated as a **regex** that matches only app names and binary names.

### `scoop info <app>`

`-v, --verbose` shows full paths and URLs. This is the only command that shows "all installed versions of an app" (`scoop list` shows only the latest version).

### `scoop status [options]`

| Option | Meaning |
|---|---|
| `-l, --local` | Only check locally installed apps; do not check online for Scoop and bucket updates |

The comparison baseline is the **local manifest**, so you must run `scoop update` first to see the truth.

### `scoop reset <app>`

Regenerates the app's shims and updates environment variables according to the manifest, thereby switching priority between multiple installed versions. Supports `*` or `-a/--all`. **Cannot switch to a version that is not installed.**

### `scoop hold <apps>` / `scoop unhold <apps>`

After `hold`, the app does not take part in `scoop update *`. `-g` applies to global apps. `scoop hold scoop` sets `hold_update_until` to one day from now.

### `scoop download <app> [options]`

Downloads to the cache and verifies the hash only; does not install.

| Option | Meaning |
|---|---|
| `-f, --force` | Overwrite the cache |
| `-s, --skip-hash-check` | Skip verification |
| `-u, --no-update-scoop` | Do not self-update first |
| `-a, --arch <arch>` | Specify the architecture |

Supports `app@version`, URL manifests, and local manifest paths.

### `scoop bucket <sub>`

```text
scoop bucket add <name> [<repo>]    # repo may be omitted for known buckets
scoop bucket list                   # Name / Source / Updated / Manifests
scoop bucket known                  # all known bucket names
scoop bucket rm <name>
```

The hard dependency of `add` is `git`; it first verifies reachability with `git ls-remote`, then clones into `buckets\<name>`. When a bucket for the same remote URL already exists, adding it again is refused.

### `scoop cache show|rm [app...]`

`rm *` or `rm -a/--all` clears the entire cache.

### `scoop config [rm] <name> [value]`

With no arguments it prints the whole configuration object; with a name and no value it prints that single entry; with a value it writes it; `rm` deletes it. See the next section for the full key table.

### `scoop export [-c|--config]`

Writes JSON (apps + buckets, plus configuration when `-c` is given) to stdout, usually redirected into scoopfile.json.

### `scoop import <path-or-url>`

Restores apps, buckets, and configuration from a scoopfile.

### `scoop alias add|rm|list`

```powershell
scoop alias add rm 'scoop uninstall $args[0]' 'Uninstall an app'
scoop alias add upgrade 'scoop update *' 'Update all apps, just like brew or apt'
scoop alias list -v
scoop alias rm <name>
```

### `scoop shim <sub>`

```text
scoop shim add <shim_name> <command_path> [[--|--%] <args>...]
scoop shim rm <shim_name> [<shim_name>...]      # note: may delete a shim generated by a manifest
scoop shim list [<regex_pattern>...]
scoop shim info <shim_name>
scoop shim alter <shim_name>                    # change the target source
```

`-g/--global` operates on global shims. Arguments after the first `--` or `--%` are passed to the shim verbatim, so to pass `-g` to the wrapped program it must come after the separator.

### The rest

| Command | Description |
|---|---|
| `scoop which <cmd>` | Find the real path of a shim/executable |
| `scoop prefix <app>` | Return the app's install directory |
| `scoop home <app>` | Open the homepage |
| `scoop depends <app>` | List dependencies in installation order |
| `scoop cat <app>` | Print the manifest; if `cat_style` is set, renders it with `bat` |
| `scoop create <url>` | Interactively generate a custom manifest |
| `scoop checkup` | Diagnostics: main bucket, long paths, developer mode, 7zip/innounp/dark, NTFS, Defender exclusions |
| `scoop virustotal [*\|app...] [-a] [-s]` | Look up VirusTotal by hash/URL; `-s` submits the URL for scanning when there is no record |

## Full configuration key set

File location is `~/.config/scoop/config.json` (`$cfgpath`).

### Paths and repositories

| Key | Value | Description |
|---|---|---|
| `root_path` | path | User-level root directory, defaults to `$Env:UserProfile\scoop` |
| `global_path` | path | Global root directory, defaults to `$Env:ProgramData\scoop` |
| `cache_path` | path | Download cache, defaults to `<root>\cache` |
| `scoop_repo` | URL | Scoop source repository, defaults to `https://github.com/ScoopInstaller/Scoop` |
| `scoop_branch` | `master`\|`develop` | Switching to `develop` gives early access to unreleased features |

### Behavior switches

| Key | Default | Description |
|---|---|---|
| `use_external_7zip` | `$false` | Use the `7z` on PATH instead of the bundled helper; if enabled but 7z is not found it aborts immediately |
| `use_lessmsi` | `$false` | Use lessmsi instead of `msiexec /a` to extract MSI |
| `use_sqlite_cache` | — | Use a SQLite cache to speed up `search` / `shim` |
| `use_git_history` | `$true` | When installing `app@version`, look in the bucket git history first |
| `no_junction` | `$false` | Do not use the `current` alias; shims/shortcuts point directly at the version directory |
| `default_architecture` | determined by the system | `64bit`\|`32bit`\|`arm64` |
| `force_update` | `$false` | Force an update to the version in the bucket |
| `debug` | `$false` | Emit verbose logs (the first step in troubleshooting) |
| `show_manifest` | `$false` | Show the manifest and ask for confirmation before installing |
| `show_update_log` | — | Do not show the changed commits during `scoop update` |
| `autostash_on_conflict` | `$false` | Automatically stash on an update conflict instead of aborting |
| `ignore_running_processes` | `$false` | When `$true`, only warn instead of aborting when the target process is running (affects reset/uninstall/update) |
| `update_nightly` | `$false` | Nightly versions update automatically after one day; otherwise `--force` is required |
| `use_isolated_path` | — | `$true` → keep the app's PATH in `SCOOP_PATH`; any other variable name may also be given |
| `shim` | — | Shim implementation: `kiennq`\|`scoopcs`\|`71` |
| `cat_style` | — | When non-empty, `scoop cat` renders with `bat`, and the value is passed as `bat --style` |

### Network and credentials

| Key | Description |
|---|---|
| `proxy` | `[username:password@]host:port`. `currentuser` in place of `username:password` uses the current user's credentials; `default` in place of `host:port` uses the system proxy; empty/unset is equivalent to `default`; `none` bypasses the system proxy and connects directly |
| `gh_token` | GitHub API token. Operations such as checkver must have it to avoid rate limits and to access private repositories |
| `virustotal_api_key` | VirusTotal API key (64-character lowercase hex) |
| `private_hosts` | Array of private hosts needing extra authentication; each element contains `match` and `headers` |

### Other

| Key | Description |
|---|---|
| `hold_update_until` | Pause Scoop self-update until the specified date; `scoop hold scoop` sets it to one day from now. Accepts `YYYY-MM-DD`, `YYYY/MM/DD`, or anything `[System.DateTime]::Parse()` can parse |

## aria2 configuration

Enabled by default once `aria2` is installed. `scoop install` / `scoop update` print a warning, which `scoop config aria2-warning-enabled false` turns off.

| Key | Default | Description |
|---|---|---|
| `aria2-enabled` | `$true` | Download with aria2c |
| `aria2-warning-enabled` | `$true` | Show the aria2 warning |
| `aria2-fallback-enabled` | `$true` | Fall back to the default downloader when aria2 fails |
| `aria2-retry-wait` | `2` | Retry interval in seconds |
| `aria2-split` | `5` | Number of connections (`-s`) |
| `aria2-max-connection-per-server` | `5` | Maximum connections per server (`-x`) |
| `aria2-min-split-size` | `5M` | Split size (`-k`) |
| `aria2-options` | empty | Array of extra aria2 options |

In CI / poor-network debugging, run `aria2-enabled false` first — that separates "download problems" from "package problems".

## Exit codes

- Most commands return `0` on success and `1` on an argument error.
- `scoop virustotal` uses a multi-bit composite code: `0` success, `1` argument error, `2` a package was judged dangerous, `4` query failure, `8` manifest not found, `16` API key not configured; `2|4|8` can combine (e.g. `6`).
- `scoop bucket add`: `0` success, `1` failure, `2` already exists / duplicate remote.
- In scripts, judge the result by `$LASTEXITCODE` only; do not match on output text.
