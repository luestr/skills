# 学习记录格式

学习记录存放在 `./learning-records/`，按顺序编号：`0001-slug.md`、`0002-slug.md` 等。目录要惰性创建：只在写下第一条记录时才创建。

它们是 ADR 在教学中的对应物：记录那些不明显、会左右未来会话的经验教训、关键洞见，以及用户自述的既有知识。它们用于计算最近发展区。

## 模板

```md
# {学到了什么或确认了什么，用简短标题概括}

{1-3 句话：学到了什么（或确认了哪些既有知识），以及为什么它对未来的会话重要。}
```

这就是全部格式。一条学习记录可以只是一个段落。价值在于记下_这件事_现在已知，以及_为什么_它改变了接下来该教什么，而不在于把各个小节填满。

## 可选小节

只有当它们确实增加价值时才写。大多数记录都不需要。

- **Status** frontmatter（`active | superseded by LR-NNNN`）：当早先的理解被证明有误并被取代时有用。
- **证据**：用户如何展示了这份理解（答对的问题、完成的练习、引用的先前经验）。当这条判断可能被重新审视时有用。
- **影响**：这对未来的会话打开了什么、排除了什么。不明显时值得记下来。

## 编号

扫描 `./learning-records/`，找到已有的最大编号，然后加一。

## 何时写一条学习记录

以下任一条成立时就写：

1. **用户展示了对某件非琐碎之事的真正理解**：不只是接触过，而是有证据表明他们能正确使用这个概念。这为接下来该教什么设定了新的下限。
2. **用户披露了既有知识**：“我已经会 X 了。”记下来，免得未来的会话重教。同时记下他们自称的_深度_。
3. **一个误解被纠正**：用户此前相信了错误的东西，现在明白了为什么。这些价值很高：它们能预示相关主题上未来的绊脚石。
4. **使命因学习而转变**：用户发现自己在意的和他们以为的不一样。交叉链接到 [[MISSION.md]] 并更新它。

### 哪些不算数

- 仅仅被讲过的材料。讲过不等于学会。等证据。
- 已作为术语定义简要记在 [[GLOSSARY.md]] 里的任何内容。不要重复。
- 逐次会话的活动日志。学习记录不是日记：它们是有决策价值的洞见。

## 取代

当较晚的一条记录与较早的一条矛盾时（用户的理解加深或纠正了），把旧记录标为 `Status: superseded by LR-NNNN`，而不是删除它。理解如何演化的历史本身就是有用的信号。
