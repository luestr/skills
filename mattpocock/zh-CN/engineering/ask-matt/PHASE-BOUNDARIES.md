# 阶段边界

**阶段**是会话内的一块工作：拷问、实现、QA。定义故意留得模糊：当你想*“好，这块结束了”*时，一个阶段就结束了。

**阶段边界**是两个阶段之间的空隙，这个决策只属于这里。阶段中途没有决策可做：继续，或者把剩下的工作拆进子 Agent。阶段中途做压缩会让 Agent 丢掉线索。

## 五个选项

| 选项       | 作用                                                    |
| ------------ | --------------------------------------------------------------- |
| **继续** | 留在会话里。完全不切换上下文。                    |
| **`/clear`** | 清空上下文窗口，从零开始。                  |
| **`/handoff`** | 写一个可携带的 markdown 文件，并用它把会话播种到任何地方。 |
| **子 Agent** | 把任务送到它自己的上下文窗口，再拿回一份报告。     |
| **`/compact`** | 压缩当前上下文，并用摘要播种一个新会话。  |

## 决策树

在边界处自上而下走。第一个**是**胜出。

**1. 你能在这个会话里继续吗？** 两件事能让答案为「是」：下一阶段需要把本阶段当作**一手资料**，或者你剩下的 [smart zone](https://www.aihero.dev/ai-coding-dictionary/smart-zone)（约 150k tokens）足够装下下一阶段。拷问 → 实现是标准的「是」：实现想要的是一字不差的原委，而不是它的摘要。继续不花成本，也不丢东西，所以要先对它作出判断，再考虑其他选项。

**2. 上下文和接下来的事无关吗？** 这个会话里的一切（探索、决策、死胡同）都是可丢弃的吗？如果是，就 **`/clear`**。它是盘面上最便宜的一步：不花时间，还回整个窗口。`/clear` 也不是终止：旧会话仍然可以恢复。

这一步判断错的代价是单向的。清空一段*相关*的上下文，你就丢掉了所构建之物背后的**缘由**，再怎么回读 diff 也找不回它。

**3. 你需要交接吗？** `/handoff` 适用面很窄。只有以下情况才需要它：

- 换到**新的 harness**（Claude → Codex），
- 搬到**新目录**或新仓库，
- 把工作交给**同事**，
- 或者在**阶段中途**分叉一项支线任务，又不打断手头的事。

这张清单就是全部条件。`/handoff` 换来的是**可携带性**：一个能旅行的文件。没有东西要旅行，就不需要它。

**4. 这项任务能 AFK 完成吗？** 它的范围是否足够紧凑，让你离开键盘、不用掌舵也能跑？那就把它交给**子 Agent**，让本会话原封不动。自动化评审是标准案例：Agent 读 diff 并汇报，这期间不需要你。

**5. 否则，`/compact`。** 上下文相关、同一个 harness、同一个目录，而你需要留在环内：决策树最终落到这里，而且经常落到这里。给它一条指令（`/compact we're going to QA this area`），让摘要保留下一阶段需要的东西。

`/compact` 是**默认选项，而不是第一顺位**。它位于最底部，因为它上面的四个问题都更便宜或更精确。人们从这里起步时的失败模式，是一个新会话对某个被摘要压平了的决策自信地判断错误。

## 一手资料与二手资料

除**继续**之外的每一步，都会把**一手资料**变成**二手资料**：实际发生过的会话，被它的摘要取代。这笔交易总是同样的形态：

| 来源                            | 信息 | 噪声 | 回旋空间 |
| --------------------------------- | ----------- | ----- | ------------ |
| 一手（继续）                | 完整        | 多  | 小       |
| 二手（`/compact`、`/handoff`） | 有损       | 更少  | 大         |

这就是问题 1 排在最前的原因。只有当继续的成本超过它的收益时，你才付出有损的代价。

## 这些都是判断问题

这些问题并不客观：每一个都掺着判断，同一个边界在两天里可能走出两种结果。价值在于**按顺序**问这些问题，并且在边界处问，而不是在工作的中途问。
