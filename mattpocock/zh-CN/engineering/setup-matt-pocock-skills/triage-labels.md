# 分诊标签

各技能以五个规范分诊角色来表述。本文件把这些角色映射到本仓库 issue 跟踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们跟踪器中的标签   | 含义                                     |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这个 issue                 |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息                   |
| `ready-for-agent`          | `ready-for-agent`    | 已完整明确，可供 AFK Agent 直接上手      |
| `ready-for-human`          | `ready-for-human`    | 需要人类实现                             |
| `wontfix`                  | `wontfix`            | 不会处理                                 |

当某个技能提到一个角色（例如“应用 AFK-ready 分诊标签”）时，使用本表中对应的标签字符串。

把“我们跟踪器中的标签”一列改成你实际使用的词汇。
