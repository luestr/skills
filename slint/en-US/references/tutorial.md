# Quickstart tutorial

The official Quickstart teaches Slint by implementing a memory game. The UI uses the Slint language, while game rules can be implemented in C++, Rust, NodeJS, or Python. The game has 16 rectangular tiles and 8 icon pairs; the player can uncover up to two tiles at once, matching tiles remain visible, and non-matching tiles are obscured again.

Tutorial chapters: Introduction, Getting Started, Memory Tile, Polishing The Tile, From One To Multiple Tiles, Creating The Tiles From Code, Game Logic, Running In A Browser, Ideas For The Reader, and Conclusion.

Source: [official Quickstart](https://docs.slint.dev/latest/docs/slint/tutorial/quickstart/).
