# Slint language topics

Slint is a declarative, reactive UI language. The official Language Guide is split into Concepts and Coding. Core topics include:

## Concepts

- Slint Language
- Reactivity
- Reactivity vs React.js

- `.slint` files, components, imports, and exports
- properties, expressions, and statements
- positioning, layouts, and sizing
- globals, repetition, and data models
- animations, states, and transitions
- functions, callbacks, and name resolution
- structs and enums

Official navigation: [Language guide](https://docs.slint.dev/latest/docs/slint/guide/language/). Prefer data-driven state, express dependencies with property bindings, and keep application logic in the host language.
