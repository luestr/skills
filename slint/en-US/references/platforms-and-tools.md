# Tools, platforms, and renderers

The official Guide covers the following complete navigation topics:

- Tooling: Visual Studio Code, manual setup, Kate, Qt Creator, Helix, (Neo-)Vim, Sublime Text, JetBrains IDE, Zed, Live Preview for Rust and C++, Slint Viewer, Figma Variable Export, and AI Coding Assistants
- Platforms: Desktop, Embedded, General Mobile Development, Android, iOS, Web, and Other Platforms
- Backends/renderers: backend overview, LinuxKMS, Qt, and Winit

Choose the target platform first, then select the integration, backend, and build configuration. See [Tooling](https://docs.slint.dev/latest/docs/slint/guide/tooling/), [Platforms](https://docs.slint.dev/latest/docs/slint/guide/platforms/), and [Backends and Renderers](https://docs.slint.dev/latest/docs/slint/guide/backends-and-renderers/).
