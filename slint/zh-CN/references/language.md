# Slint language 主题

Slint 是声明式、响应式的 UI language。官方 Language Guide 分为 Concepts 与 Coding 两部分。核心主题包括：

## Concepts

- Slint Language
- Reactivity
- Reactivity vs React.js

- `.slint` 文件的组件、导入与导出
- properties、表达式与 statements
- position、布局与尺寸
- globals、repetition 与 data models
- animations、states 与 transitions
- functions、callbacks、name resolution
- structs 与 enums

官方导航：[Language guide](https://docs.slint.dev/latest/docs/slint/guide/language/)。使用时优先保持状态由数据驱动，让 property binding 表达依赖关系，并将业务逻辑放在宿主语言中。
