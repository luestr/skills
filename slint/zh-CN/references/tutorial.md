# Quickstart 教程

官方 Quickstart 通过实现 memory game 学习 Slint：UI 使用 Slint language，游戏规则可由 C++、Rust、NodeJS 或 Python 实现。游戏包含 16 个矩形 tile、8 对图标；玩家一次翻开最多两个 tile，配对成功后保持可见，否则重新遮挡。

教程章节：Introduction、Getting Started、Memory Tile、Polishing The Tile、From One To Multiple Tiles、Creating The Tiles From Code、Game Logic、Running In A Browser、Ideas For The Reader、Conclusion。

来源：[官方 Quickstart](https://docs.slint.dev/latest/docs/slint/tutorial/quickstart/)。
